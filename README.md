
# Student Performance Analyzer

A simple beginner-friendly Python project that calculates a student's total marks, average, and grade.

## Features

* Takes student name and subject marks as input
* Calculates total marks
* Calculates average marks
* Assigns a grade based on the average
* Displays the student's performance

## Technologies Used

* Python

## How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Run `student_performance.py`.
4. Enter the student's name and marks when prompted.


## Concepts Used

* Variables
* User Input
* Arithmetic Operations
* Conditional Statements
* Python `print()` function
